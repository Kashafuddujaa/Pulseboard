# PulseBoard

A modern full-stack SaaS analytics dashboard that helps businesses monitor key metrics, visualize performance, and gain AI-powered insights through an intuitive and responsive interface.

## ✨ Features

* Secure JWT Authentication
* Interactive Analytics Dashboard
* Real-Time Metrics & Charts
* AI-Powered Business Insights
* Team & Workspace Management
* Reports & Data Export
* Role-Based Access Control
* Responsive UI

## 🛠️ Tech Stack

**Frontend**

* React
* TypeScript
* Tailwind CSS
* React Router
* Recharts

**Backend**

* Node.js
* Express.js
* PostgreSQL
* Prisma ORM
* JWT Authentication
